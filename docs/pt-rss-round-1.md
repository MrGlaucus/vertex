# PT 刷流第一轮交付

> 本文记录第一轮交付。当中关于内存预占、恢复队列与辅种保护尚未实现的边界，已由[后续交付](pt-rss-follow-up.md)更新；当前行为以该文档为准。

## 配置方法

1. 在「基础组件 → 下载器」按机器设置最大下载数量和最小剩余空间。
2. 可选择启用「预计空间保护」。默认关闭，以兼容旧配置。状态有效期默认 120 秒，应大于下载器的轮询间隔。
3. 在「规则组件 → RSS 规则」选择下载器组，并设置优先级。
4. 在「任务配置 → RSS 任务」勾选参与分流的所有下载器及选择规则。新规则组只使用规则与任务下载器列表的交集，不回退到组外。
5. 运行「试运行」，检查命中规则、目标机器、各候选机器的排除原因，然后启用任务。

例如小种规则绑定小盘机器、大种规则绑定大盘机器。RSS 的下载任务上限会同时限制所有候选机器；需要不同上限时，将其留空或设为 0，分别设置每台下载器的最大下载数量。

## 分流语义

- 拒绝规则优先。选择规则按优先级数值从大到小匹配，同优先级按 RSS 任务中选择规则的配置顺序。只使用第一条命中规则的组、路径和分类。
- 规则组留空时使用任务下载器列表。没有选择规则时默认接受；配置了选择规则但均未命中时拒绝。
- 旧 `client` 单下载器覆盖继续支持，不要求该机器同时出现在任务列表中，但实际目标机器也必须通过容量及速度检查。
- 编辑旧规则时，保持原单机器选择会保留旧语义；改变下载器组后切换到新组语义；清空组会移除旧覆盖。
- 下载任务数越少优先；速度排序从低到高；剩余空间排序从高到低。预计空间保护启用后，剩余空间排序使用扣除待下载和预占后的空间。
- 试运行不会预占容量或发送下载请求；它检查规则和当前容量，不检查历史去重、小时推送上限、休眠时间、免费/HR、辅种命中等条件。实际执行结果可能随状态变化而不同。

## 容量与并发

普通添加统一经过 Client 的同步预占，包括 RSS、站点搜索推送和影视订阅。每台下载器共享任务名额；编辑下载器、重建实例不会清空预占。原有跳过校验的辅种路径不占普通下载名额。

预计空间 = 下载器报告的剩余空间 − 已登记种子的剩余下载量 − 尚未确认的新任务大小。

添加后的预计空间不得低于最小剩余空间。启用保护后，大小未知、空间未知或状态过期均拒绝添加。RSS 使用合成 hash 时先获取种子文件，使用真实 hash 预占；文件推送优先使用种子文件中的实际大小。

- 请求中及已接受但尚未出现在轮询结果中的任务，继续占用名额和空间。
- 新鲜状态中出现相同 hash 且已有大小信息后，将预占转交给实际种子状态，不重复计数。
- 明确的 HTTP 客户端拒绝释放名额；超时、服务器错误等结果不确定的请求继续保留，避免立即重发。
- HTTP 已接受后，流量或历史记录写入失败不会撤销预占，也不会作为再次添加的理由。
- 下载器列表显示包含预占的下载数、预占数量和待核实数量。
- 同一 RSS 的定时轮次不重叠执行。停用后停止新添加；已经发出的请求无法撤回。

## 当前边界

本轮预占保存在单个 Node.js 进程内，不保证跨进程、重启期间或外部手动添加的并发容量一致性。持久化恢复队列、自动核实及人工处理入口在后续轮次实现。

结果不确定或已接受但始终未出现在下载器中的请求不会自动过期释放；可能持续占用名额，应检查对应下载器及错误日志。不要依靠反复重启来重发未知结果的任务。

空间计算以下载器报告的磁盘数据为基础。不同下载器即使共享同一磁盘，也各自计算预算；本轮不提供共享磁盘的统一预算或按保存路径查询分区。需为共享磁盘分别配置余量。预分配文件可能导致剩余下载量被保守重复扣除。

自动辅种匹配、标签补偿及共享文件保护属于后续轮次，本轮没有迁移参考项目的这些增强。

## 验证

后端：`npm test`。测试覆盖规则分流、优先级、组内不可用、旧单下载器、并发预占、空间边界、状态过期、轮询衔接、请求不确定、数据库失败、文件添加、试运行与实际 RSS 路径。

代码检查：`npm run eslint`。Windows 签出若保留 CRLF，现有全仓检查会触发换行规则，可用 `npx eslint app --rule "linebreak-style: off"` 检查其他规则；本轮修改的后端文件使用 LF。

前端在 `webui` 安装锁定依赖（`npm ci --legacy-peer-deps`），生成主题（`node dark`、`node light`、`node cyber`）后执行 `npm run build`。无 Git 标签时版本号回退到 package.json。

本地已完成自动测试、修改文件的 ESLint 和生产构建。没有连接真实下载器或启动生产服务；上线前仍需用独立测试下载器验证磁盘报告、任务计数和添加确认。
